# Mobile App Store (Command Line, Java)

A small Java command-line app store demo. Browse and search a sample catalog,
view app details, simulate installing or uninstalling apps, and see installed
apps. Install state is saved in `data/installed_apps.txt`.

## Run

Install JDK 11 or newer. From this folder, compile and launch:

```powershell
javac Main.java
java Main
```

Installation is simulated; this demo does not download or install Android apps.
